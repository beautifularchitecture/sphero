# Personas — Sphero Mini Chat Control

## P1 — Robot Operator (primary)

**Role:** The user themselves, operating the Sphero Mini from their own Linux machine on the local network.  
**Goals:** Control the robot's movement, speed, and LED color by typing chat messages into a local website; observe the robot's current state (direction, orientation, color, position) on a live stats panel.  
**Pain Points:** No existing chat-driven interface for the Sphero Mini; must type commands into a web UI rather than using a phone app.  
**Context:** Single user, no collaborators or reporting needed in this MVP. Personal learning and tinkering project.  
**Tech Comfort:** Medium — comfortable with a web chat UI and basic robot concepts.
